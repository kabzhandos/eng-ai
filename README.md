# 🎓 EngAI — Адаптивный ИИ-тренажер английской грамматики

**EngAI** — веб-приложение для изучения грамматики английского языка (CEFR A1–B2) с использованием генеративного искусственного интеллекта (LLM).

> 💡 **Главная ценность:** Полный отказ от статических баз вопросов. ИИ генерирует уникальные задания в реальном времени, исключая возможность списать или зазубрить правильные ответы.

---

## ⚡ Ключевые архитектурные решения под Gemini Free Tier (15 RPM / 1500 RPD)

Для бесплатной работы без превышения лимитов Google Gemini Free Tier реализованы три оптимизации:

1. **Пакетная прегенерация (Batching 10x):**
   * Приложение **никогда не запрашивает у ИИ 1 вопрос**.
   * За 1 обращение к Gemini генерируется пачка из **10 уникальных заданий** с готовыми ответами и пояснениями на русском языке.
   * Ученик получает беспрерывную практику на 10–15 минут всего за **1 сетевой запрос**.

2. **Очередь запросов (Rate Limiter 15 RPM):**
   * Серверный синглтон `GeminiRateLimiter` распределяет сетевые запросы с защитным интервалом **4.2 сек** (~14.2 RPM), исключая ошибки `429 Too Many Requests`.

3. **100% Локальная проверка ответов (0 токенов):**
   * Сверка ответа ученика происходит моментально на бэкенде.
   * При ошибке ученик сразу видит предгенерированное объяснение правила из пакета задания, экономя 100% токенов на проверке.

## 🛠️ Стек технологий

* **Full-Stack:** Next.js 16 (App Router, React 19, TypeScript)
* **Стилизация:** Tailwind CSS 4, Lucide Icons, Mobile-First адаптивность
* **ИИ-ядро:** Vercel AI SDK (`@ai-sdk/google`) + Gemini 3.5 Flash Lite + Zod Structured Outputs
* **База данных:** SQLite (для локального старта) / PostgreSQL (для продакшна) + Prisma ORM
* **Безопасность:** Хеширование `bcryptjs`, сессии JWT (`jose`) в `httpOnly` куках

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения (`.env`)
Создайте файл `.env`:
```env
DATABASE_URL="file:./dev.db"
GOOGLE_GENERATIVE_AI_API_KEY="ВАШ_КЛЮЧ_GEMINI"
JWT_SECRET="super-secret-jwt-key-for-engai-development-at-least-32-chars"
```

### 3. Инициализация базы данных и демо-данных
```bash
npx prisma db push
npx tsx prisma/seed.ts
```

### 4. Запуск сервера разработки
```bash
npm run dev
```
Откройте в браузере: **`http://localhost:3000`**

## 📋 Основные разделы приложения

* **`/`** — Интерактивное дерево грамматических тем A1–B2 с индикацией усвоения.
* **`/placement`** — Входное адаптивное тестирование из **20 вопросов** от A1 до B2.
* **`/practice/[topicId]`** — Экран тренировки с мгновенной отдачей заданий из буфера и блоком Smart Retry.
* **`/analytics`** — Личный дашборд ученика: точность ответов, срез по CEFR, глобальный рейтинг и история попыток.
* **`/teacher`** — Кабинет учителя: создание групп, копирование инвайт-кодов и радар «Зон зависания» (Bottlenecks).

## 🌐 Как выложить в интернет

### Вариант А: Мгновенно за 1 минуту (Localtunnel)
Чтобы показать проект прямо сейчас с работающего компьютера:
```bash
npx localtunnel --port 3000
```

### Вариант Б: Бесплатно 24/7 (Vercel + Neon.tech)
1. Создайте бесплатную базу PostgreSQL на **[Neon.tech](https://neon.tech)**.
2. В `prisma/schema.prisma` укажите `provider = "postgresql"`.
3. Загрузите репозиторий на GitHub.
4. Импортируйте проект на **[Vercel.com](https://vercel.com)** и укажите переменные `DATABASE_URL`, `GOOGLE_GENERATIVE_AI_API_KEY`, `JWT_SECRET`.
5. Примените миграции: `npx prisma db push && npx tsx prisma/seed.ts`.
